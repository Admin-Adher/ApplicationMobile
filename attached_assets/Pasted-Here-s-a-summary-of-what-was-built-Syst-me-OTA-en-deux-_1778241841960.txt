Here's a summary of what was built:

Système OTA en deux couches — ce qui a été ajouté :

hooks/useOtaUpdate.ts — Vérifie expo-updates en arrière-plan au démarrage et à chaque retour en premier plan. Utilise require() dynamique pour ne jamais crasher si expo-updates n'est pas configuré.

components/OtaUpdateBanner.tsx — Bannière violette qui s'anime depuis le haut de l'écran quand un bundle JS est prêt, avec un bouton "Redémarrer" qui applique la mise à jour instantanément.

app.json — Configuré avec updates.url pointant vers EAS Update et runtimeVersion.policy: appVersion.

CI .github/workflows/build-apk.yml — Ajout d'un job publish-ota qui publie le bundle JS via eas update --branch production (en ~2-3 min, sans rebuild natif).

Une étape manuelle à faire — ajouter le secret EXPO_TOKEN dans votre dépôt GitHub :

Allez sur https://expo.dev → Settings → Access tokens → Create token
Dans GitHub : Settings → Secrets and variables → Actions → New repository secret
Nom : EXPO_TOKEN, valeur : le token Expo
Une fois configuré, chaque git push main publiera automatiquement une mise à jour OTA en quelques minutes, sans que les utilisateurs aient à réinstaller l'APK.
